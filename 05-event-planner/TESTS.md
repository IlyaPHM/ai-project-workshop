# Проверка проекта

1. Для исходного примера сумма времён равна 90 минутам. Переходы и завершение входят в эти 90 минут.
2. Сумма 1200 + 800 + 600 + 900 + 700 равна 4200; резерв 800; полный итог 5000; остаток 0. У статей есть количество и цена, арифметика верна.
3. При бюджете 3000 расходы вместе с резервом не превышают 3000; исходная смета не выдаётся за новую.
4. В классе нет бега; в программе без выбывания каждый остаётся участником. Нет неоговорённой еды.
5. При сокращении до 60 минут изменены расписание и инструкции ведущим, а не только заголовок.
6. Запасной сценарий выполним без техники и укладывается в те же ограничения.
7. /экспорт переносит все условия и итоговую версию в новый чат.

Запиши: что проверили, что произошло, что исправили, повторная проверка. ИИ может ошибиться даже при правильной инструкции; исправление считается частью работы.
