# Размещение материалов на GitHub

Репозиторий набора — [IlyaPHM/ai-project-workshop](https://github.com/IlyaPHM/ai-project-workshop). Ниже описан способ повторно загрузить материалы или развернуть свою копию. Адрес опубликованной страницы проверяйте в Settings → Pages → Visit site.

## Как загрузить через браузер

1. Войди в свой GitHub и создай новый репозиторий с выбранным именем. Для открытого доступа детям подойдёт Public. Владелец должен быть IlyaPHM. При доступе через другую организацию проверь владельца отдельно.
2. Распакуй ZIP с набором на компьютере. Открой папку ai-project-workshop.
3. В репозитории выбери Add file → Upload files. Перетащи СОДЕРЖИМОЕ папки: index.html, README.md, остальные файлы и пять папок проектов. Не загружай один ZIP вместо содержимого. index.html должен оказаться в корне репозитория.
4. Сохрани файлы через Commit changes. Названия файлов и папок сохраняй как в наборе.
5. Открой README.md на GitHub и проверь переход в каждый проект и START_PROMPT.txt.

## Как дать детям общую страницу с кнопками

1. В репозитории открой Settings → Pages.
2. В Build and deployment выбери Source → Deploy from a branch.
3. Выбери ветку, в которую загружены файлы, обычно main, и папку /(root). Нажми Save.
4. Дождись публикации. GitHub указывает, что изменения могут публиковаться до 10 минут. Возьми адрес из блока Visit site — это проверенная ссылка, которую нужно дать детям.
5. Проверь страницу в отдельном окне без входа в GitHub: копирование пяти запросов и запуск игры.

Наличие GitHub Pages зависит от типа репозитория, тарифа и правил организации. Для публичного репозитория GitHub Free поддерживает Pages. На общей странице текст запросов встроен; браузер может скопировать его без обращения к ИИ. Никаких ключей и платных API страница не использует.

## Как детям читать материалы

Основной путь: открыть опубликованную страницу, выбрать проект, нажать «Скопировать запрос», вставить его в свой чат. На GitHub можно открыть START_PROMPT.txt, затем Raw и скопировать текст. Если чат умеет читать ссылки, можно отправить ссылку на конкретный файл и попросить следовать ему, но ручное копирование остаётся надёжным запасным путём.

HTML на странице репозитория показывается как код. Для игры нужна опубликованная страница Pages либо локальный файл из распакованного ZIP. Одной ссылки на аккаунт IlyaPHM недостаточно: детям нужно дать ссылку на репозиторий или страницу набора.

## Что входит в публикацию

Публикуются инструкции, вымышленные учебные примеры, игра и общая страница. Исходные DOCX, личные истории участников, ответы детей, переписки, фотографии и учётные данные в набор не включены. Примерные цены и характеристики учебных животных не выдаются за реальные объявления.

Официальная инструкция: [создание GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [настройка ветки публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
