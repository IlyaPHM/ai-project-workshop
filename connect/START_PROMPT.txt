Помоги мне сделать собственный учебный проект с настоящими ответами ИИ. Я школьник, работаю в браузерном ChatGPT или DeepSeek. Нужна одна законченная HTML-страница со встроенными CSS и JavaScript, без npm, сервера на моём компьютере и внешних библиотек.

Сначала спроси, какой проект я делаю: игра, истории людей, подбор питомца, помощник артисту или организатор праздников. Затем уточняй по одному вопросу. Предложи минимальную первую версию, дождись выбора и создай готовый HTML.

Для ИИ используем уже подготовленный преподавателем API. В интерфейсе нужны поле «Адрес API» и отдельное поле type=password «Код доступа команды». Значения вводит пользователь. Не проси настоящий ключ DeepSeek; не вставляй код доступа в исходный код, URL, localStorage, примеры или сообщения об ошибках. Храни его только в памяти страницы. На GitHub публикуется HTML без кодов и ключей.

HTTP-контракт:
POST <адрес API>/v1/chat
Authorization: Bearer <код команды>
Content-Type: application/json
Тело: {"project":"stories","messages":[{"role":"user","content":"Помоги записать воспоминание"}],"instructions":"Короткая инструкция моего помощника"}
project может быть game, stories, pets, artist или events. messages — от 1 до 12 сообщений с role user/assistant, последнее user; не больше 4000 символов на сообщение. instructions — до 2000 символов; весь запрос до 24 КБ. Модель и максимальная длина ответа задаются преподавателем на сервере.
Успех: {"reply":"Текст ответа","truncated":false,"remaining":{"student":29,"classroom":199},"requestId":"..."}. Ошибка: {"error":{"code":"...","message":"Понятное объяснение"},"requestId":"..."}.
GET <адрес API>/v1/usage с тем же Authorization проверяет код и показывает remaining, limits и resetsAt, не тратит запрос генерации. GET /health без кода возвращает ready.

Используй обычный fetch. Во время запроса отключай повторное нажатие кнопки, показывай ожидание и сохраняй ввод при ошибке. Обрабатывай 401, 403, 429 и 503 понятным сообщением. Не делай автоматических повторов и запросов при каждом нажатии клавиши. Ответ отображай через textContent, а не innerHTML. Веди историю user/assistant в памяти, отправляй последние 11 предыдущих сообщений вместе с новым; при смене проекта очищай историю. Добавь «Новый диалог».
В игре ИИ вызывается только отдельной кнопкой для подсказки или разговора с персонажем, не в игровом цикле. Для питомцев дай явно вымышленный каталог, чтобы помощник сравнивал карточки и не выдумывал настоящий приют. Для истории отделяй факты от художественных добавлений. Для организатора проверяй сумму времени и бюджета. Для артиста создавай оригинальный текст и не обещай аудиозапись.

Верни полный файл для скачивания, если умеешь. Если не умеешь, дай весь HTML одним блоком и короткую инструкцию сохранения через обычный текстовый редактор в UTF-8, имя index.html, тип «Все файлы». После создания предложи три ручные проверки и одно небольшое улучшение на выбор. Не утверждай, что тестировал страницу, если не запускал её.
