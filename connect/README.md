# Подключение ИИ к своему проекту

Твой сайт может отправлять вопросы в учебный API преподавателя и показывать ответы DeepSeek. Ключ DeepSeek остаётся на сервере. От преподавателя ты получаешь адрес API и личный код команды.

## Быстрая проверка

1. Открой [проверочную страницу](index.html).
2. Введи адрес API, если он ещё не указан, и свой код команды. Нажми «Проверить доступ».
3. Выбери проект и задай вопрос. Это уже настоящий запрос к DeepSeek, если преподаватель завершил настройку сервера.
4. Счётчик покажет остаток запросов. Не отправляй повторно, пока идёт ответ.

## Как создать свою страницу

1. Скопируй [запрос для ChatGPT или DeepSeek](START_PROMPT.txt) в новый чат.
2. Выбери проект и объясни, каким должен быть его интерфейс.
3. Получи готовый HTML. Открой его в браузере и введи адрес API и свой код.
4. Сделай одно изменение. Проверь неверный код, успешный ответ и работу нового диалога.

Оригинальные запросы из папок пяти проектов нужны для работы помощника прямо в чате. Для подключения к своему сайту используй именно START_PROMPT.txt из этой папки: здесь описан HTTP-контракт.

## Минимальный запрос из JavaScript

```javascript
// Значения читаются из полей страницы. Код доступа не сохраняй в исходнике.
const apiUrl = document.querySelector('#apiUrl').value.trim().replace(/\/$/, '');
const accessCode = document.querySelector('#accessCode').value.trim();
const response = await fetch(apiUrl + '/v1/chat', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer ' + accessCode
  },
  body: JSON.stringify({
    project: 'stories',
    messages: [{ role: 'user', content: 'Помоги записать воспоминание о первой поездке' }],
    instructions: 'Сначала задай один вопрос, потом жди моего ответа.'
  })
});
const data = await response.json();
if (!response.ok) throw new Error(data.error?.message || 'Ошибка API');
document.querySelector('#answer').textContent = data.reply;
```

Для нескольких запросов есть [готовый класс ClassroomAI](client.js). Его можно подключить тегом `<script src="client.js"></script>` и создать `new ClassroomAI(apiUrl, accessCode)`. Методы: `chat(project, messages, instructions)` и `usage()`. Проверочная страница самодостаточна: скопировав один index.html, можно открыть её без дополнительных файлов.

## Правила подключения

| Поле | Что передавать |
| --- | --- |
| project | game, stories, pets, artist или events |
| messages | 1–12 сообщений user/assistant, последнее user |
| content | До 4000 символов на сообщение |
| instructions | До 2000 символов своей инструкции |
| Authorization | Bearer и код команды |

Для диалога отправляй историю вместе с новым вопросом. API не хранит историю за тебя. Сменил тему или инструкцию — начни новый диалог. Пример для питомцев использует вымышленные карточки; для настоящего каталога передай согласованные сведения в instructions или сообщении.

## Если ответ не пришёл

- 401 — проверь код или попроси преподавателя выдать новый.
- 403 — преподавателю нужно разрешить адрес твоего сайта в ALLOWED_ORIGINS.
- 429 — закончился дневной лимит или запросы идут слишком часто. Подожди указанное время либо обратись к преподавателю.
- 503 — настройка не завершена, сервис приостановлен или DeepSeek занят.
- Ошибка сети — проверь адрес и интернет. Открытие HTML двойным щелчком поддерживается, пока преподаватель разрешил файловые страницы.

Не публикуй свой код команды на GitHub и не добавляй его в ссылку на сайт. На общем компьютере после работы очисти поле кода или закрой страницу. В проекте достаточно вымышленных данных: настоящие фамилии, контакты и семейные документы для упражнения не нужны.
