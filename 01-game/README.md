# Игра DTA

Своя браузерная игра с управлением, доставками и победой. Ориентир на занятие: 60–90 минут; время зависит от опыта команды и доступа к сервису.

## Что сделать

1. Открой [готовую игру](game.html). Нажми «Начать» и попробуй управление. Если работаешь в GitHub, открой игру через общую страницу GitHub Pages или скачай весь набор ZIP и распакуй его: GitHub показывает исходный HTML, а не запускает игру.
2. Открой [стартовый запрос](START_PROMPT.txt), скопируй весь текст в новый чат и отправь его.
3. Ответь, что файл уже есть. Прикрепи game.html из распакованного набора. Если загрузка недоступна, можно открыть файл в обычном Блокноте и скопировать содержимое. Если это сложно, выбери создание с нуля.
4. Выбери одно изменение и попроси готовую новую версию файла. Сохрани исходную игру отдельно, новую назови game-v2.html.
5. Открой новую версию в браузере, проверь её по списку. Затем добавь ещё одно небольшое улучшение: другой герой, новые подписи или награда.
6. Запиши три собственных решения и покажи прохождение одного заказа. Сохрани последнюю рабочую версию.
