# Проверка проекта

1. Помощник сначала узнаёт тему, а не сразу пишет готовую песню.
2. После выбора замысла есть 8 строк куплета и 4 строки припева. Три исходных слова использованы по смыслу.
3. Текст читается вслух; спорные рифмы проверяются на слух, а не только по буквам.
4. На «измени только припев» куплет сохраняется.
5. Не появляется обещание готового аудиофайла без инструмента генерации музыки.
6. После /экспорт можно запустить того же помощника в новом чате.

Запиши: что проверили, что произошло, что исправили, повторная проверка. ИИ может ошибиться даже при правильной инструкции; исправление считается частью работы.
