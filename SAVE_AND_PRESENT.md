# Сохранение и защита проекта

Сохраняй результат после каждого работающего изменения. Для игры оставляй отдельные файлы game.html и game-v2.html. Для помощника сохраняй инструкцию запуска, согласованные исходные данные, итоговый текст и одну проверку. Если чат умеет создавать файлы, попроси TXT; если нет — скопируй текст в обычный документ.

## Запрос для сохранения

Скопируй в чат:

> Подготовь сохранение проекта. Отдельно выдай актуальную инструкцию для нового чата, подтверждённые исходные данные, последнюю рабочую версию результата, список моих решений и следующий маленький шаг. Не выдумывай выполненные проверки. Если умеешь создать скачиваемый файл — создай, иначе дай текст для копирования. Для игры верни полный HTML, а не кусочки изменений.

## Текст для продолжения

В новом чате сначала отправь стартовую инструкцию, затем сообщение:

```text
Продолжаем мой проект.
Название:
Для кого делаем:
Что уже работает:
Мои решения:
Подтверждённые данные:
Последняя версия результата:
Что проверили и что произошло:
Следующий шаг:
Не начинай всё заново. Сначала кратко подтверди, что понял состояние.
```

Заполни поля своими сведениями. Для игры приложи последнюю рабочую версию game.html. Чтобы закончить работу сегодня, достаточно сохранить текст и файл; публиковать личный результат не требуется.

## Защита за две минуты

1. 20 секунд: кому помогает проект и какую задачу решает.
2. 60 секунд: показать основной сценарий от ввода до результата.
3. 20 секунд: назвать три решения команды.
4. 20 секунд: показать одну проверку, ошибку или исправление и сказать, что будете улучшать дальше.
