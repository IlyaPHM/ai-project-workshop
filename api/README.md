# Учебный API DeepSeek

Cloudflare Worker принимает запросы детских проектов, проверяет код команды и лимиты, затем обращается к DeepSeek с ключом, который хранится только в Cloudflare. Код сервера и примеры находятся в GitHub; сервер работает независимо от компьютера преподавателя.

## Выбранное размещение

Cloudflare Workers и один SQLite Durable Object на учебную группу. Отдельную базу данных создавать не нужно: Wrangler создаёт хранилище счётчиков при публикации. На Workers Free доступны SQLite Durable Objects; облачные операции ограничены квотами платформы. Обращения к DeepSeek оплачиваются отдельно с баланса владельца ключа.

Лимиты по умолчанию: 200 попыток генерации на группу в сутки, 30 на команду в сутки, 5 в минуту на команду. Длина ответа ограничена 800 токенами, число сообщений — 12, размер HTTP-тела — 24 КБ. Сутки считаются по UTC, сброс в 00:00 UTC, то есть в 03:00 по Москве. Счётчики переживают перезапуск Worker. Неуспешная попытка обращения к DeepSeek тоже расходует лимит; автоматических повторов нет.

Это ограничения числа и размера обращений, а не точный денежный лимит. Итоговая стоимость зависит от актуального тарифа DeepSeek и длины текста. Баланс, тариф и расходы проверяются в кабинете DeepSeek.

## Что нужно для запуска

1. Аккаунт Cloudflare с доступом к Workers.
2. Действующий ключ DeepSeek и доступный баланс.
3. Один раз развернуть Worker и добавить два секрета: DEEPSEEK_API_KEY и STUDENT_CODES_JSON.

## Запуск владельцем через терминал

Детям эти действия не нужны. Команды выполняются из папки api. Установи Node.js и pnpm либо используй рабочую среду, где они уже есть.

```sh
pnpm install --frozen-lockfile
pnpm exec wrangler login --scopes account:read user:read workers_scripts:write
pnpm run codes
pnpm run types
pnpm run check
pnpm test
pnpm exec wrangler deploy --dry-run
pnpm run bootstrap
```

Команда bootstrap создаёт Worker и загружает только хеши кодов команд. До добавления DEEPSEEK_API_KEY генерация закрыта, /health показывает ready: false. Владелец вводит ключ в Cloudflare Dashboard → Workers & Pages → ilyaphm-classroom-ai → Settings → Variables and Secrets → Add → Secret, имя DEEPSEEK_API_KEY. После сохранения проверь /health: ready должно стать true. Следующие обновления кода выполняй командой pnpm run deploy. Альтернативный способ добавить секреты через CLI:

```sh
pnpm exec wrangler secret put DEEPSEEK_API_KEY
pnpm exec wrangler secret bulk .secrets/cloudflare-secrets.json
```

Ключ вводится в защищённом запросе CLI либо в Cloudflare Dashboard → Workers & Pages → нужный Worker → Settings → Variables and Secrets → Add → Secret. Не передавай ключ аргументом команды и не помещай его в файл wrangler.jsonc. STUDENT_CODES_JSON содержит хеши кодов, сами коды есть только у преподавателя и детей.

В Dashboard также можно задать оба секрета вручную. Код доступа к Cloudflare и ключ DeepSeek вводит владелец. После изменения секрета сохрани и разверни новую версию, если интерфейс попросит это сделать.

## Что отдать детям

Адрес опубликованного Worker без пути, например https://имя-проекта.поддомен.workers.dev, и отдельный код из .secrets/student-codes.csv каждой команде. Пример адреса выше — образец, фактический адрес показывает Wrangler после успешного deploy.

В [проверочной странице](../connect/index.html) можно заранее указать действительный адрес, изменив DEFAULT_API_URL. Никакие коды или DeepSeek-ключи в HTML не добавляются. Проверка доступна также по GET /health: ready должно быть true. Далее проверь GET /v1/usage с кодом команды и один POST /v1/chat.

## Настройки

Все несекретные настройки описаны в wrangler.jsonc. MODEL выбирается только на сервере. API_ENABLED=false останавливает новые генерации. CLASSROOM_ID задаёт отдельное пространство счётчиков; изменение этого значения начинает новую группу с новыми счётчиками. Для обычного обновления кода оставляй CLASSROOM_ID прежним.

ALLOWED_ORIGINS — точные origin через запятую, без путей и завершающего слеша, например https://ilyaphm.github.io. Для нового домена добавь его origin и повторно разверни Worker. ALLOW_FILE_ORIGIN=true разрешает запросы из локальных HTML и некоторых встроенных предпросмотров с Origin: null. Проверка origin дополняет коды доступа; сама по себе она не защищает от сторонних программ, поэтому действующий код обязателен всегда.

## Отключение и обновление кодов

Чтобы отключить одну команду, удали её объект из STUDENT_CODES_JSON и обнови секрет в Cloudflare. Чтобы выдать новые коды, сначала сохрани старый приватный файл, затем сгенерируй новый набор в чистой локальной папке и замени секрет. Счётчики привязаны к id команды; при сохранении id новый код наследует её дневной расход. Не меняй id или CLASSROOM_ID ради обычного обновления кода.

## Данные и проверка

Диалог передаётся в DeepSeek. Наш Worker не сохраняет тексты диалогов в хранилище и не пишет их, коды и ключи в собственные логи. В счётчиках хранятся только id команды, число попыток и срок окна. Платформы Cloudflare и DeepSeek могут обрабатывать технические данные по своим условиям. Не отправляйте реальные личные истории детей в учебном тесте.

В тестах DeepSeek заменён имитацией ответа, расходов на провайдера нет. Проверяются авторизация, ограничения ввода, CORS, ошибки провайдера, атомарность лимитов при одновременных запросах и сохранение счётчиков после выгрузки объекта. Боевой ответ проверяется отдельно после добавления ключа.

Версия совместимости зафиксирована на 2026-10-23, поддерживаемой локальным workerd. При обновлении Wrangler можно обновить дату и повторить проверки.
