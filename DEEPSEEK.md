# Работа через DeepSeek

Те же стартовые запросы можно вставить в браузерный [DeepSeek](https://chat.deepseek.com/). Отдельно размещать модель на GitHub для этого не требуется. Доступ к сервису, регистрация и ограничения аккаунта проверяются педагогом перед занятием.

## Как запустить

1. Открой новый чат DeepSeek.
2. Скопируй START_PROMPT.txt своего проекта и отправь текст целиком. Специальных системных настроек не требуется: это обычное первое сообщение.
3. Ответь на первый вопрос. Для быстрого примера отправь /демо.
4. Проверь работу по TESTS.md. Следование инструкции зависит от модели: если она пропускает шаг, напиши «Вернись к инструкции. Сейчас нужен только один вопрос и ожидание моего ответа».
5. Для продолжения в другом сервисе используй /экспорт. Скопируй инструкцию и состояние в новый чат; история переписки сама не переносится.

## Особенности игры

Не рассчитывай на одинаковый интерактивный предпросмотр в разных сервисах. Открой готовую игру из набора отдельно в браузере. Если DeepSeek может прочитать прикреплённый HTML, попроси изменить один элемент и вернуть полную версию. Если вложение недоступно, вставь полный текст файла из обычного текстового редактора или выбери создание с нуля. Если модель не может выдать скачиваемый файл, действует ручное сохранение из TROUBLESHOOTING.md.

## Что именно можно хранить на GitHub

Инструкции, учебные данные, HTML-игру и общую страницу. GitHub Pages публикует статические файлы; он не запускает модель DeepSeek как сервер. Наша общая страница открывает выбранный чат, а текст нужно вставить самостоятельно.

Если позже понадобится собственный сайт с настоящей генерацией ответов через DeepSeek, это следующий отдельный этап: серверная часть, авторизация, хранение ключа на сервере, учёт расходов и данных. В официальном API требуется ключ; ключ нельзя размещать в открытом репозитории или в HTML страницы. В текущем наборе API не используется и оплачивать его для занятия не нужно.

Источники: [официальный сайт DeepSeek](https://www.deepseek.com/), [документация API](https://api-docs.deepseek.com/), [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
