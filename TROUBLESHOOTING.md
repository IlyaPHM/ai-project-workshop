# Если что то не работает

## Чат не открывает ссылку GitHub

Открой START_PROMPT.txt самостоятельно. Скопируй текст и вставь его в новое сообщение. Не нужно подключать GitHub к аккаунтам детей. Проверь, что скопировано начало и конец запроса.

## Кнопка копирования не сработала

Открой текст запроса на общей странице, нажми в поле и выдели всё сочетанием Ctrl+A, затем Ctrl+C. На телефоне удерживай палец в поле и выбери выделение текста. На странице есть кнопка «Выделить текст».

## Вместо игры виден код

В репозитории GitHub HTML не запускается. Открой игру через GitHub Pages или скачай весь набор через Code → Download ZIP, распакуй и дважды нажми game.html. На телефоне проще использовать опубликованную страницу Pages.

## В ChatGPT нет предпросмотра

Открой game.html отдельно в браузере. Если у аккаунта есть Visualize, можно попросить интерактивный результат в чате; эта возможность зависит от аккаунта. Отсутствие предпросмотра не мешает использовать уже готовый файл.

## Модель вернула только код и не дала скачать файл

Сначала напиши: «Если умеешь создавать файлы, прикрепи полный game.html для скачивания. Если не умеешь, скажи прямо». Для ручного пути на Windows:

1. Скопируй только содержимое блока HTML: от <!doctype html> до </html>, без строк с тройными обратными кавычками.
2. Открой обычный Блокнот, вставь текст, выбери Файл → Сохранить как.
3. Укажи имя game-v2.html, тип «Все файлы», кодировку UTF-8.
4. Проверь, что файл не называется game-v2.html.txt. Открой его браузером.

Если сохранение затрудняет работу, педагог помогает с этим действием, а ребёнок формулирует изменение и проверяет игру. Другой запасной путь — продолжить с исходной готовой версией и сохранить запрос изменения для следующего занятия.

## Игра не реагирует на клавиши

Нажми «Начать», затем на поле игры. Стрелки и WASD поддерживаются; на телефоне используй экранные кнопки. После потери фокуса игра ставится на паузу — нажми «Продолжить».

## После изменения игра сломалась

Открой исходную версию, она остаётся рабочей. Прикрепи сломанный файл и напиши: «После изменения [описание] при действии [что нажал] происходит [что видишь]. Исправь только эту ошибку и верни полный HTML». Не добавляй новые функции до повторной проверки.

## Помощник задаёт сразу много вопросов

Напиши: «Следуй стартовой инструкции. Задай только следующий один вопрос и дождись моего ответа». Если переписка стала запутанной, сохрани факты и перезапусти помощника в новом чате.

## Чат достиг лимита или потерял контекст

Сохрани последнюю рабочую версию и краткое состояние по SAVE_AND_PRESENT.md. После восстановления доступа вставь START_PROMPT.txt и это состояние. Можно перейти в другой доступный сервис, проверив результат заново.
