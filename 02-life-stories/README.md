# ИИ создание историй людей

Помощник берёт интервью и пишет историю по подтверждённым фактам. Ориентир на занятие: 40–60 минут; время зависит от опыта команды и доступа к сервису.

## Что сделать

1. Скопируй [стартовый запрос](START_PROMPT.txt) в новый чат ChatGPT или DeepSeek.
2. Для первого прогона выбери вымышленный пример. Посмотри, задаёт ли помощник один вопрос за раз.
3. Отвечай кратко. Можно написать «не помню», «пропустить» или «готово». Для быстрой проверки вставь [пример](SAMPLE.txt).
4. Проверь список фактов до написания рассказа. Исправь ошибки и подтверди правильную версию.
5. Получи рассказ и названия. Измени один факт и проверь, что исправление попало во весь текст.
6. Отправь /проверить, затем /экспорт. Сохрани инструкцию помощника и готовую историю отдельными текстами. Настоящие воспоминания используй только с согласия рассказчика.
