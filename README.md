# Проекты с ИИ для работы в браузере

Пять учебных проектов для детей и педагога. Открой проект, скопируй стартовый запрос в свой ChatGPT или DeepSeek и выполняй шаги. Программировать и устанавливать среду разработки не требуется. Для игры есть готовая основа, которую можно открыть браузером и изменить вместе с ИИ.

## Порядок проектов

| Очередь | Проект | Первый результат |
| --- | --- | --- |
| 1 | [Игра DTA](01-game/README.md) | Город, машина и три доставки |
| 2 | [Истории людей](02-life-stories/README.md) | Интервью и рассказ по фактам |
| 3 | [Подбор питомца](03-pet-match/README.md) | Анкета и обоснованный выбор |
| 4 | [Помощник артиста](04-artist/README.md) | Куплет и припев |
| 5 | [Организатор праздников](05-event-planner/README.md) | Программа и смета |

## Начни здесь

1. Выбери один проект. Для первого занятия начинаем с игры.
2. В папке проекта открой START_PROMPT.txt. Скопируй весь текст в новый чат и отправь. Можно пользоваться готовой общей страницей index.html с кнопками копирования.
3. Отвечай на вопросы помощника. Делай одно улучшение за раз.
4. Открой TESTS.md и проверь результат. Сохрани последнюю рабочую версию.
5. На защите покажи работу проекта, три собственных решения и одну найденную ошибку с исправлением.

Ссылки на GitHub можно дать ChatGPT для чтения, но доступ к ним не гарантирован. Если чат не прочитал файл, вставь содержимое START_PROMPT.txt вручную. Ученику не нужен аккаунт GitHub для просмотра публичных материалов.

## Как устроен набор

В каждой папке есть README.md с маршрутом, START_PROMPT.txt для вставки в чат, SAMPLE.txt с учебным примером и TESTS.md с проверками. В 01-game лежит game.html — готовая автономная игра. Четыре ИИ-помощника работают в диалоге с выбранной моделью; отдельного приложения или Telegram-бота в наборе нет.

- [Памятка педагогу](TEACHER.md)
- [Размещение на GitHub](GITHUB.md)
- [Работа через DeepSeek](DEEPSEEK.md)
- [Если что-то не работает](TROUBLESHOOTING.md)
- [Сохранение и продолжение](SAVE_AND_PRESENT.md)
- [Источники и адаптация исходных идей](SOURCES.md)

Чтобы пользоваться набором с компьютера без GitHub Pages, скачай репозиторий через Code → Download ZIP, распакуй и открой index.html. Для работы ИИ интернет и доступ к выбранному сервису понадобятся; сама игра работает автономно.
