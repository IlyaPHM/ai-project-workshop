# ИИ помощник подбора питомца

Помощник сопоставляет условия семьи с учебным каталогом животных. Ориентир на занятие: 40–60 минут; время зависит от опыта команды и доступа к сервису.

## Что сделать

1. Скопируй [стартовый запрос](START_PROMPT.txt) в новый чат. Каталог уже включён, добавлять файлы не нужно.
2. Пройди анкету как вымышленная семья. Начни с [примера](SAMPLE.txt) или отвечай по одному вопросу.
3. Посмотри, связал ли помощник рекомендации с условиями семьи. Потребуй объяснить неизвестные сведения.
4. Измени одно ограничение, например «дома уже есть кошка» или «гулять совсем не можем». Проверь новый подбор.
5. Попробуй случай, в котором никто не подходит. Честный ответ «нет подходящих кандидатов» тоже считается рабочим результатом.
6. Выбери кандидата, получи вопросы приюту и план адаптации. Отправь /проверить и /экспорт. Сохрани инструкцию, анкету и пример подбора.
